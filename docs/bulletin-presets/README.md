# Bulletin presets

Presets are ordinary bulletin template files (the same format as **Bulletins > Export**).
They are data, not code: the app contains no country-specific ids.

- `rwanda-eidsr.json` – Rwanda's weekly eIDSR bulletin. Its program, attribute and data
  element ids only exist on Rwanda's DHIS2 instance. Import it there with
  **Bulletins > Import JSON**, then choose the completeness data sets and add logos.

To make a preset for another country, build the bulletin in the app and export it.
